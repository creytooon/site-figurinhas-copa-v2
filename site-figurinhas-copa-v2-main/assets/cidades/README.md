# Fotos das 16 Cidades-Sede

Coloque aqui uma foto **JPG** pra cada cidade com **o nome exato listado abaixo**.
O sistema tenta carregar a foto local primeiro; se não achar, usa URL remota; se essa falhar, mostra o fallback elegante com o nome da cidade.

## Tamanho recomendado
- **Largura**: 1280px – 1600px
- **Altura**: 720px – 1080px
- **Proporção**: 16:9 ou 4:3 (paisagem)
- **Tamanho do arquivo**: até 300 KB (use [tinyjpg.com](https://tinyjpg.com) pra comprimir)

## Onde baixar (sugestões gratuitas)

1. **Unsplash** — https://unsplash.com (uso comercial livre)
   - Busca: `New York skyline night`, `Mexico City Angel de la Independencia`, etc.
2. **Pexels** — https://pexels.com (uso comercial livre)
3. **Pixabay** — https://pixabay.com (uso comercial livre)
4. **Wikimedia Commons** — https://commons.wikimedia.org (licença CC, verifique cada foto)

## Critérios de boas fotos
- **Skyline noturno**: combina perfeitamente com o tema dark do site
- **Marcos icônicos**: Empire State (NY), Golden Gate (SF), Anjo da Independência (CDMX), Estátua Liberdade (NY)
- **Sem rostos identificáveis**: evita problemas de direito de imagem
- **Sem texto/logos**: pra parecer profissional

## Dica
O site aplica automaticamente: dessaturação leve + escurecimento + tom dourado.
Por isso fotos **muito coloridas funcionam bem** — o tratamento deixa elas no tom do site.
